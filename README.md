# Task Manager

A simple Java CLI task manager built to learn and practice object-oriented programming.

## Features

- Create tasks
- List tasks
- Complete tasks
- Delete tasks
- Prevent duplicate task IDs
- Basic input validation and error handling

## Concepts practiced

- Classes and objects
- Constructors
- Encapsulation
- Methods and method chaining
- ArrayList
- Exception handling
- Separation of responsibilities

## Technologies

- Java
- Git / GitHub

## Future improvements

- Task persistence
- Unit tests
- Due dates and priorities
