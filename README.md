# Task Manager

A simple Java CLI task manager built to learn and practice object-oriented programming.

## Features

- Create tasks
- List tasks
- Complete tasks
- Delete tasks
- Prevent duplicate task IDs
- Basic input validation and error handling

## Project Structure

```text
src/
└── main/
    └── java/
        ├── Main.java
        ├── Task.java
        └── TaskManager.java
```

## Concepts Practiced

- Classes and objects
- Constructors
- Encapsulation
- Methods and method chaining
- ArrayList
- Exception handling
- Separation of responsibilities

- Java
- Git / GitHub
